## 一、六种商业单据

| 单据类型 | 适用场景 | 关键字段 |
|---------|---------|---------|
| **发票 (Invoice)** | 已完成服务的收款凭证 | 发票号、开票日期、到期日、付款条款 |
| **报价单 (Quote)** | 售前向客户提供的预估价格 | 有效期、报价明细、备注 |
| **收据 (Receipt)** | 收到款项的确认凭证 | 收款日期、收款方式、对应发票 |
| **采购单 (Purchase Order)** | 向供应商下单采购 | 供应商、收货地址、期望交付日 |
| **形式发票 (Proforma)** | 预开发票，常用于外贸 | 预估金额、有效期、贸易条款 |
| **贷记通知单 (Credit Note)** | 退货或价格调整的冲账 | 关联原发票号、冲账金额、原因 |

**通用字段**：单据号（自动生成 `INV-202601-0001` 格式）、客户、项目明细（含税）、小计/税额/合计、备注。

## 二、客户与产品管理

### 客户管理
- 字段：名称、邮箱、电话、地址、**税号**（支持 VAT / 统一社会信用代码 / EIN 等）
- 增删改查 + 列表搜索（按名称）
- 单据中选择客户自动填充信息
- 删除时如有引用会提示

### 产品 / 服务库
- 字段：名称、单价、默认税率、描述
- 一次创建永久复用
- 单据中可一键添加产品到明细行（基于税率和默认价格）
- 改产品不影响已开单据

## 四、多格式导出

每张单据支持 **3 种导出方式**：

### 1. 打印 / 另存为 PDF
- 一键调用浏览器 `window.print()`
- 选择"另存为 PDF"即可得到 A4 排版
- 不依赖任何第三方 PDF 库

### 2. Excel / CSV 导出
- 导出明细行的 CSV（Excel 可直接打开）
- 用于财务对账、税务申报
- 字段：项目名称、单价、数量、税率、合计

### 3. Word / DOCX 导出
- 真实可编辑的 .docx 文件（基于 docx.js 库）
- 客户可继续修改、加批注
- 适合需要二次编辑合同的场景

## 五、仪表盘与状态追踪

主界面顶部一屏展示：

| 指标 | 含义 | 计算方式 |
|------|------|---------|
| 💰 **已收总额** | 已标记为"已付款"的所有单据金额 | `status === 'paid'` 求和 |
| ⏳ **待收款** | 未到期 + 未付款的金额 | `status === 'pending'` 求和 |
| ⚠️ **逾期金额** | 已过到期日仍未付款的金额 | 自动检测（每日重算）|
| 📄 **单据总数** | 所有类型单据数量 | 含全部状态 |

### 单据状态自动管理

每个单据根据日期自动判定状态：

- **草稿 (Draft)**：刚创建未发送
- **待付款 (Pending)**：未到期或未标记
- **已付款 (Paid)**：用户手动标记
- **逾期 (Overdue)**：当前日期 > 到期日 且 未付款（**自动判定，无需手动**）

> 可对每个单据手动标记"已付款" + 添加付款日期/方式备注。

## 八、数据备份与迁移

### 导出备份（JSON）
- 一键导出全部数据为 `.json` 文件：
  - 所有单据（含明细）
  - 客户列表
  - 产品库
  - 公司设置
  - 库存数据
  - 定期账单规则
  - 语言偏好
- 文件名格式：`invoiceforge-backup-2026-01-15.json`

### 从备份恢复
- 选择之前的 JSON 文件
- 自动恢复所有数据
- 完成后自动刷新页面

### 跨设备迁移
```
旧电脑:  导出备份 → 得到 invoiceforge-backup-XXX.json
                                    ↓ 复制 U盘 / 网盘 / 邮件
新电脑:  打开 InvoiceForge → Settings → 导入备份 → 全部数据恢复 ✅
```

> **提示**：备份文件是纯 JSON，跨设备直接导入即可。

## 十、技术架构

### 文件结构
```
InvoiceForge/
├── index.html              # 单文件入口（包含所有 DOM）
├── css/
│   └── style.css           # 全部样式（含响应式 + 4 模板）
├── js/
│   ├── app.js              # 业务逻辑（单据 / 客户 / 产品 / 仪表盘）
│   ├── i18n.js             # 中英双语字典
│   └── templates.js        # 4 套模板渲染
├── docs/                   # 用户文档（中英）
└── tools/                  # 冒烟测试脚本
```

### 依赖（仅 CDN）
- **Tailwind CSS** (v3)：UI 框架
- **Font Awesome 6**：图标
- **SheetJS** (xlsx)：Excel 导出
- **docx.js**：DOCX 导出

> 无需 `npm install` / 无需后端 / 无需数据库

### 数据存储
- 所有数据存于浏览器 `localStorage`
- 单浏览器单账号上限 5-10 MB（足够 10000+ 张单据）
- 跨设备 = 导出 JSON → 导入 JSON

### 浏览器兼容
- ✅ Chrome / Edge / Brave 90+
- ✅ Firefox 88+
- ✅ Safari 14+
- ❌ IE（不支持）

### 安全与隐私
- **数据完全本地**：不上传任何服务器
- **无追踪**：无 Google Analytics、无 Sentry
- **开源可审计**：所有 JS 文件可读，无混淆

## 🎯 典型使用流程

1. **首次使用**：设置公司信息 → 上传 Logo → 选择默认币种和税率
2. **添加客户**：客户管理 → 新建 → 填名称/邮箱/税号
3. **添加常用产品**（可选）：产品库 → 填名称/价格
4. **创建单据**：单据 → 新建 → 选客户 → 填明细 → 保存
5. **预览 / 导出**：在单据列表点"查看" → 选模板 → 打印 或 导出 PDF/CSV
6. **标记付款**：预览单据时点击"标记为已付款" → 自动同步到仪表盘
7. **定期备份**：每周导出一次 JSON 备份到网盘
